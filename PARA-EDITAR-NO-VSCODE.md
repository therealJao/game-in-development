# Edição no VS Code

Abra EscapeCode.code-workspace. Comece por **dist/configuracao.js** para editar nomes e ajustes básicos.

Salve, feche o jogo e abra o mesmo Escape-Code.exe. Não mova a pasta dist para longe dele.

Leia **GUIA-DE-EDICAO.md** para a lista completa dos arquivos e exemplos de edição segura.
